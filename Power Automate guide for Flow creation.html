UPDATE Overwrite a row by S.No

Use for: UPDATE_BD_ROW, UPDATE_ENGAGEMENT_ROW, UPDATE_OPS_SESSION, UPDATE_SOLUTIONING_ROW. The UPDATE_OPS_ROW (single checkbox) has a special note at the bottom.

⚡
When a HTTP request is received
+
📊
Update a row
+
↩
Response
1
Create the flow
Name: e.g. CRM – Update BD Row. Trigger: "When a HTTP request is received".
2
Trigger schema — same as ADD but add "sno" at the top
Take the ADD schema for the same tracker and add one extra property "sno" before all other fields. Example for BD:
{ "type": "object", "properties": { "sno": {"type":"string"}, // ← ADD this line "Client": {"type":"string"}, "Concern Person": {"type":"string"}, // ... all other fields same as ADD ... } }
ℹFor Engagement UPDATE, also add "egId": {"type":"string"} alongside sno.
3
Add "Update a row"
+ New step → Excel Online (Business) → "Update a row". Select same Location / Library / File / Table as before. Then set the key lookup:
Key Column
S.No
Type or select the column that holds the row number. For Solutioning it may be "SNo" — check your actual Excel header.
Key Value
⚡ Dynamic content → sno (from trigger body)
PA will find the row where S.No = sno and update it
After setting the key, the rest of the Excel column fields appear. Map them to the dynamic content the same way as ADD — every field except sno itself.
⚠For Ops UPDATE_OPS_SESSION: map only the session fields (EG.ID, Company, dates, consultants etc.). Do not overwrite the checklist checkbox columns — leave those fields empty so PA skips them.
4
Add Response → Save → copy URL
Status Code
200
Body
{"success":true}
UPDATE_BD_ROW: 'paste-url-here', UPDATE_ENGAGEMENT_ROW: 'paste-url-here', UPDATE_OPS_SESSION: 'paste-url-here', UPDATE_SOLUTIONING_ROW:'paste-url-here',
⚠ Special case: UPDATE_OPS_ROW (single checkbox)
This flow updates one checklist field at a time when you tick a checkbox. It receives sno, the column name as field, and the new value. Because PA's Update a row UI doesn't support dynamic column selection, use this approach:
💡In the Update a row step, click Show advanced options — all checklist column fields appear. For each checklist column, click inside the field and type the expression:

if(equals(triggerBody()?['field'], 'Feedback Report'), triggerBody()?['value'], null)

Change 'Feedback Report' to that column's exact name for each field. PA skips null fields and only writes the targeted column.
// Trigger schema for UPDATE_OPS_ROW { "type":"object", "properties": { "sno": {"type":"string"}, "field": {"type":"string"}, // e.g. "Feedback Report" "value": {"type":"string"} // e.g. "Done" or "" } }
